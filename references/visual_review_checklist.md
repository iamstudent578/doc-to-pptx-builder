# 視覺校對檢查清單

步驟 4 拿到每頁的轉圖結果後，針對每一張圖逐項檢查。發現任何一項有問題，
記錄「頁碼＋問題描述」，回頭修正 pptx 後再重新轉圖檢查一次。

## 文字問題
- [ ] 有沒有文字被文字框邊界裁切、看不到完整內容
- [ ] 有沒有文字跟圖片/圖表重疊
- [ ] 標題與內文的字級是否維持一致的階層（同類型頁面字級應該統一）
- [ ] 條列項目是否對齊整齊（項目符號、縮排一致）
- [ ] 有沒有明顯的錯字或格式殘留（例如忘記替換的預留文字 "Lorem ipsum"、範本佔位字）

## 圖片與圖表問題
- [ ] 圖片有沒有變形（長寬比例被拉伸）
- [ ] 圖片解析度是否足夠清晰，沒有明顯模糊或鋸齒
- [ ] 圖表的座標軸、圖例是否完整可讀，數字不會被截斷
- [ ] 圖片/圖表位置有沒有超出投影片邊界

## 版面與風格問題
- [ ] 留白是否失衡（例如內容都擠在左上角，右下大片空白）
- [ ] 這一頁跟其他同類型頁面的版面風格是否一致
- [ ] 配色對比是否足夠，文字在背景上清楚可讀
- [ ] 頁尾/頁碼/LOGO 等固定元素位置是否一致（如果簡報有使用範本母片）

## 內容一致性（跟大綱/原文件對照）
- [ ] 這頁呈現的數字/事實跟原文件是否一致，沒有在生成過程中被誤植
- [ ] 這頁的內容是否跟大綱（outline.json）規劃的重點相符，沒有偏題或遺漏

## 修復迴圈的判斷原則
- 版面微調類問題（文字溢出、留白失衡）→ 直接調整字級/位置後重轉圖確認。
- 如果同一頁修了 2-3 輪還是有問題，通常代表這頁塞的內容量本身超過版面負荷，
  應該回頭到步驟 3（甚至步驟 2 的大綱）考慮拆頁或精簡，而不是繼續在版面上硬調。
